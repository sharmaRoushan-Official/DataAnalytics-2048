2. What is Data Analysis?
------------------------------------------------------------------
Data Analysis is the process of examine, cleaning, transform, and interpreting data to find useful information, patterns and insight that help in decision-making.
-----------------------------------------------------------------------------------------------------------------

In Simple Word:
Data Analysis means converting raw data into useful information.
---------------------------------------------------------------------------------------------

RAW DATA
   |

   |

   |

   |

   |
